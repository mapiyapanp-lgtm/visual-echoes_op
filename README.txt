Visual Echoes poster download page

Files:
- index.html: webpage with the poster image embedded for easy preview and deployment
- styles.css: page styling
- script.js: download button
- assets/visual-echoes-poster.png: original uploaded poster
- assets/visual-echoes-poster.jpg: optimized copy used by the embedded webpage

Open index.html locally to test. To make it available publicly by URL for QR scanning, upload the files to a static hosting service such as GitHub Pages, Netlify, or Vercel. A local file or ChatGPT preview is not a public hosting URL.
